# GPT-6 Astra Outbound System

Outbound sales skills for Codex, running on the Pastel MCP (`https://mcp.heypastel.com/mcp`): 20 skills in `skills/`, and 12 optional Codex custom agents in `team/`.

For any prospecting, LinkedIn outreach, reply handling, or pipeline question, start with `skills/command-center/SKILL.md`. It picks the right skill for each job and links the shared house rules and Pastel tools guide in `skills/command-center/shared/`.

Nothing reaches a prospect without the user's explicit yes, unless they switched autopilot on.

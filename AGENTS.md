# Pastel Outbound System

This repo is an outbound sales system: 17 skills under `skills/`, a 14-agent team (`agents/` for Claude Code, `codex-agents/` for Codex), and the Pastel MCP at `https://mcp.heypastel.com/mcp`.

For any sales, outbound, prospecting, LinkedIn, or pipeline task, start with `skills/outbound-os/SKILL.md`. It routes to the one skill each job needs, and holds the shared rules (`references/rules.md`) and Pastel tool map (`references/pastel-mcp.md`).

Review mode is the default: every Pastel request waits for the user's yes.

# Security

This plugin is plain markdown skills plus one hosted MCP server (`https://mcp.heypastel.com/mcp`). It ships no scripts, hooks, or binaries, and it never asks for or stores credentials: signing in to Pastel is handled by your AI client over OAuth.

Every action that reaches a prospect (comments, invitations, messages, sequences) is drafted for your review and only runs after an explicit yes, unless you turn autopilot on yourself.

## Reporting a vulnerability

Please email **loup@heypastel.com** with a description and steps to reproduce. Don't open a public issue for security reports.

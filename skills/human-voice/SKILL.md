# Human voice

Three passes over every draft. Facts never change; only the wording does.

## 1. Cut

Delete everything the reader would skip: throat-clearing openers, restated context they already know, sign-offs that repeat the ask, and any sentence that would still be true if you swapped in another company's name.

## 2. Swap

Replace every word you wouldn't say out loud to a customer across a table with the one you would.

| Instead of | Say |
|---|---|
| reach out | write / get in touch |
| empower, enable | let, help |
| streamline, optimize | cut, speed up, simplify |
| seamless, robust, holistic | say what it actually does |
| solution, platform | the thing's name, or what it does |
| touch base | talk |
| revolutionize, transform | change, fix |

## 3. Point

The message makes one point and asks one thing. If a second idea sneaks in, it becomes the next message. On LinkedIn, keep it to what fits on a phone screen without scrolling, in plain sentences: no bullet points, bold, or exclamation marks in a DM.

## When reviewing a batch

Put the drafts side by side. Rewrite any whose shape you could predict from the others, until each one could only have been written to its own recipient.

## Output

Each draft rewritten, followed by one line on what changed, e.g. `cut: opener, repeated ask · swap: "streamline" → "speed up"`.
